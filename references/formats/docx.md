# Word/DOCX 路线协议

Word 路线必须以当届官方 `.doc`/`.docx` 模板为底稿。仅凭源码或 Markdown 不得声明
格式合规。

## Required steps

1. 复制 `inputs/official-template/` 中的官方文件作为论文底稿，不新建空白文档；
   记录底稿的 SHA-256。
2. 保留模板的页面设置（纸张、页边距、分节）与样式（标题、正文、题注、公式编号），
   新内容一律套用既有样式，不手工改字号。
3. 生成 1–3 级目录，深度与当届规则一致；目录域在交付前更新一次。
4. 图片按原始宽高比插入，只设置高度或宽度之一；表格使用模板的题注样式。
5. 运行时探测 LibreOffice（`soffice`）：
   - 可用时用命令行导出 PDF，记录命令与页数；
   - 不可用时保留 DOCX，并明确要求用户用 Word 导出 PDF，然后重新执行视觉检查。
6. 交付前登记 PDF 预览产物，运行
   `python scripts/render_audit.py --workspace <workspace>` 生成版面报告。

## Format checks

- 页面设置与样式来自官方模板，而不是默认 Normal 模板。
- 图表编号、题注、公式编号与正文引用一致。
- 匿名信息（作者、单位、页眉页脚）已按当届规则处理。
- 最终 PDF 的页数与当届规则一致。

## Stop conditions

- 官方 `.doc`/`.docx` 模板缺失：不进入排版，先补齐 INTAKE。
- 无法导出 PDF：不得宣称交付完成，交回用户用 Word 导出后继续。
- 只能靠手工排版维持外观：说明模板样式未被正确继承，回到第 2 步修正。
