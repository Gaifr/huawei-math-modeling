# LaTeX 路线协议

LaTeX 路线必须让编译产物在视觉结构上对齐当届官方模板。仅凭源码不得声明格式合规。

## Required steps

1. 把 `inputs/official-template/` 中的当届官方模板作为结构基准，逐项比对页面尺寸、
   页边距、字体、字号、行距、标题层级和页眉页脚。
2. 运行时探测工具链：`xelatex`（中文论文优先）、`pdflatex`、`bibtex`/`biber`。
   记录发现的版本；找不到时在报告中写明“无法编译”，不得假定成功。
3. 使用相对路径引用 `figures/` 与 `results/tables/` 中的资源，保证工作区可整体搬移。
4. 图片按相对路径插入，避免使用 `[H]` 强制位置；普通浮动体交给 LaTeX 排版，必要时
   用 `\FloatBarrier` 或按章分组，图多时优先压缩图表体积而不是强行固定位置。
5. 存在参考文献时先编译一次生成 `.aux`，再运行 BibTeX/Biber，最后连续编译两遍消除
   交叉引用为空的问题。
6. 编译成功后检查最终 PDF：页数是否符合当届规则、字体是否嵌入、元数据与文件名是否
   符合匿名与命名要求。
7. 报告中记录使用的命令、页数和 PDF 的 SHA-256。

## Format checks

- 目录层级与官方模板一致，且不超过当届规则允许的深度。
- 图表 caption、公式编号和交叉引用在 PDF 中真实可见，而不是只在源码中存在。
- 模板中要求的匿名性（作者、单位、致谢、页眉）已处理。

## Stop conditions

- 缺少当届官方模板：不进入排版，先补齐 INTAKE。
- 工具链缺失或编译失败：保留源码与日志，明确记录“未验证”，不得宣称格式合规。
- 只能通过破坏模板结构才能编译：回到模板比对，先修正结构再继续。
